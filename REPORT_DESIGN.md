# Checkra report design

Recommended production report sections:

1. Submission information
2. Overall similarity score and grade
3. Sources reviewed
4. Source-type breakdown
5. Exact / near / semantic match breakdown
6. Highlighted matched passages
7. Source evidence and URLs
8. Grammar findings
9. AI-writing signal (probabilistic)
10. Natural rewrite changes
11. Exclusion settings
12. Methodology and coverage disclaimer
13. QR/report verification identifier
