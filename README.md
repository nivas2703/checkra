# Checkra

**AI-Powered Writing & Integrity Checker**

> **Check. Verify. Improve.**

Checkra is a comprehensive, evidence-grounded writing analysis and verification platform. It evaluates document similarity against live web sources, validates linguistic quality, provides AI-powered evidence assessment and text rewriting, and generates tamper-verifiable integrity reports—all with zero permanent document storage.

Every similarity percentage, highlighted passage, and citation review generated by Checkra is strictly derived from retrieved and verifiable source text.

---

## Important Notice & Integrity Principles

> [!IMPORTANT]
> **Checkra does not claim "100% accurate plagiarism detection."**
> 
> Checkra performs **evidence-based writing similarity and source verification**. High similarity scores indicate shared phrasing or contextual correspondence with accessible web sources; they do **not** independently determine plagiarism, academic misconduct, or improper intent. Academic integrity decisions require human evaluation of quotations, citations, disciplinary norms, and contextual factors.

## Key Features

- **Multi-Format Document Ingestion**: Direct upload and text extraction from **PDF**, **DOCX**, **TXT**, **MD**, and **HTML** files, complete with word count, character count, page estimates, and reading time computation.
- **Three-Tier Similarity Engine**:
  - **Level 1 — Exact Match**: Configurable consecutive n-gram sequence matching (4 to 15 words) with exact character and token offset mapping.
  - **Level 2 — Near Match**: Fuzzy sequence alignment detecting word substitutions, deletions, insertions, and phrasing variations.
  - **Level 3 — Semantic Similarity**: Cosine vector comparison evaluating sentence-level and paragraph-level meaning using either an OpenAI-compatible embedding API or Checkra's built-in deterministic mathematical subword/stem vectorizer.
- **Deterministic Similarity Scoring**:
  $$\text{Overall Similarity} = (\text{Exact} \times 0.65) + (\text{Near} \times 0.25) + (\text{Semantic} \times 0.10)$$
- **Web Search & Grounding via SearXNG**: Live web retrieval with multi-query generation and concurrency-controlled webpage extraction.
- **Gemini AI Evidence Review**: Evaluates retrieved matching passages for attribution context and citation quality, with resilient handling and dedicated retry on upstream capacity spikes (`AI_REVIEW_UNAVAILABLE`).
- **Grammar & Style Analysis**: Built-in rule-based linguistic engine (with optional LanguageTool integration) providing categorized suggestions for grammar, spelling, punctuation, style, and clarity.
- **AI Rewrite Studio**: 5 distinct rewriting styles (*Clear & Natural*, *Academic & Readable*, *Professional*, *Concise*, *Simple English*) designed to enhance clarity while preserving core factual assertions.
- **Tamper-Verifiable Integrity Reports**: Multi-page printable HTML reports, complete JSON evidence packages, and official public verification seals with scannable QR codes at `/verify/:id`.
- **Session-Only Privacy & Security**: Complete in-memory session isolation. Documents and raw submissions are never stored to disk or retained in permanent databases.

## Web Search Engine (SearXNG)

Checkra integrates with **SearXNG**, an open-source metasearch engine, to locate candidate web sources without vendor lock-in.

### Local Development Setup
During local development, Checkra connects to SearXNG running locally via Docker:

```bash
docker run -d --name searxng -p 8080:8080 \
  -e "SEARXNG_BASE_URL=http://localhost:8080/" \
  searxng/searxng:latest
```

In your `.env`:
```env
SEARCH_ENGINE=searxng
SEARCH_API_URL=http://localhost:8080/search
```

### Production Deployment Note
> [!NOTE]
> For production deployments, do not rely on `localhost:8080`. Deploy SearXNG in your private container network or cluster (e.g., via Docker Compose, Kubernetes, or a managed reverse proxy) and point `SEARCH_API_URL` to that internal service (e.g., `http://searxng:8080/search` or `https://searxng.internal.yourdomain.com/search`).

If the search engine is unreachable, Checkra degrades gracefully into **Local Comparison Mode**, logging the status transparently without crashing.

## Privacy & Security Architecture

1. **Zero Disk Storage**: Uploaded files and analyzed texts are processed in-memory for the duration of the user's active session. No user documents are ever persisted to relational tables or flat files.
2. **Credential Isolation**: Secrets such as `GEMINI_API_KEY` are read exclusively by server-side processes and are never returned in API responses, injected into HTML templates, or exposed via telemetry endpoints.
3. **SSRF & Retrieval Protection**: External webpage fetching enforces strict private IP blocking (preventing requests to internal metadata services, loopback interfaces, or private RFC 1918 subnets) and enforces payload size caps.
4. **HTML Sanitization**: All user-submitted content and third-party web extracts undergo strict HTML element escaping before presentation or report generation.

## Limitations

- **Web Coverage**: Checkra can only discover similarities against public web sources indexed and accessible by the configured search provider. Gated academic repositories, paywalled publications, and private intranets are inaccessible unless provided as direct reference inputs.
- **Probabilistic AI Detection**: Any stylistic or AI-writing indicators provided are statistical estimates and should never be used as singular evidence of machine generation.
- **Dynamic Content**: Webpages requiring complex client-side JavaScript single-page rendering or human verification challenges (CAPTCHAs) cannot be retrieved by automated crawlers.
